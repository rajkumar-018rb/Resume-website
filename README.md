# Simple Resume Website

A clean, responsive, and professional personal resume website built using **HTML5 and CSS3**. This project was created as part of a Web Development Internship to practice semantic HTML, modern CSS layouts, responsive design, and professional presentation of personal information.

## 🚀 Project Overview

This website presents the professional profile of **Rajkumar Sant** in a simple single-page layout.

It includes:

- Personal profile
- About Me section
- Education details
- Technical skills
- Development experience
- Featured projects
- Contact information
- LinkedIn and GitHub profile links

The website is designed to work on desktop, tablet, and mobile devices.

## ✨ Features

- Responsive single-page resume website
- Clean and professional user interface
- Sticky navigation bar
- Smooth navigation between sections
- Profile and introduction section
- About Me section
- Education timeline
- Technical Skills section
- Development Experience section
- Featured Projects section
- Contact section
- Clickable email link
- LinkedIn profile link
- GitHub profile link
- Mobile-friendly layout
- CSS Flexbox and Grid layouts
- Hover effects and transitions

## 🛠️ Technologies Used

- **HTML5** – Website structure and semantic elements
- **CSS3** – Styling and responsive design
- **Flexbox** – Layout alignment
- **CSS Grid** – Skills and project layouts
- **Media Queries** – Responsive design
- **CSS Transitions** – Hover effects and animations
